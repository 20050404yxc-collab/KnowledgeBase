# 知序 · 个人知识库

当前版本：**test0.03**。这是 Windows 桌面开发测试版，采用 Electron + React / TypeScript + Python + SQLite。

本次已按[项目编码与分层规范](docs/确认页/工程规范/项目编码与分层规范.md)整改存量代码：React 按探索、知识、资料、接口和用量组织；Electron 分开窗口、IPC 与后台生命周期；Python 采用入口、应用、领域、基础设施四层，由装配点注入实现。相关说明见[存量代码整改](docs/确认页/工程规范/存量代码整改.md)，后续开发遵守根目录 [AGENTS.md](AGENTS.md)。已有功能、数据库结构、凭据身份和用户数据位置保持兼容。

## 启动

本机开发环境已准备。双击根目录的 `启动知序.cmd`，或执行：

```powershell
npm run build
npm start
```

开发时使用 `npm run dev`。首次克隆请先按照 [开发环境说明](docs/确认页/个人知识库/开发环境.md) 创建 `.venv`、安装锁定依赖和 Electron 运行时，然后构建。当前程序依赖项目内 `.venv` 和 `node_modules`，尚未提供独立安装包。

## 当前可用

- 知识新建、编辑、删除、中文关键词检索；常用 / 在学 / 归档自动计算，支持手动固定。
- 拖入文档、选择文件或粘贴本地路径；读取 MD、TXT、DOCX、文字版 PDF，显示位置、引用摘录及解析局限。
- 附件默认仅用于本次会话；点击“保留”才将快照加入资料库。退出后清理会话副本，不修改用户原件。
- 本次文件、知识库及混合范围提问；无 API 时显示本地片段，支持离线编辑和搜索。
- 配置 Responses、Chat Completions 兼容接口及 Anthropic Messages 协议；模型与基础地址可填写。API Key 通过 Windows 凭据管理器保存。
- 完整模型响应经结构和引用 ID 检查后收录；同标题、相同正文或已完成的同问题复用已有知识；不覆盖手动编辑。同标题但正文不同的回答会明确显示未新建条目，可手动换标题保存补充。
- 关联卡片优先展示最多两条相关旧知识，其余由模型提出拓展；点击拓展才生成。数量不足会明确显示。
- 调用记录包括成功、失败、取消和中断。接口未返回的用量显示“未知”；用户填写价格后按调用时价格估算，分币种统计。

简单说：先在本地写、查、读，配置自己的接口后再使用 AI 学习和积累功能。

## API 使用

在“API 配置”中填写名称、**实际协议**、基础地址、模型 ID 和 API Key。基础地址包含供应商要求的前缀，例如 `https://api.openai.com/v1`；不要填写完整的 `/responses` 或 `/chat/completions` 路径。远程地址需要 HTTPS，本机服务可使用 HTTP。

“测试连接”会发起真实模型调用，可能产生费用。开发验收使用模拟接口，没有调用付费服务。主流模型品牌不代表协议相同，请按实际服务填写；真实 GPT / DeepSeek / Claude / Grok 兼容性仍需使用你的配置验证。生成模型不会自动启用向量能力。

## 数据与支持边界

默认数据位于 Electron 的 Windows 用户数据目录，确切路径可在界面底部展开查看；SQLite 正文及资料副本位于该目录，API Key 存于 Windows 凭据管理器。备份前先关闭应用，复制完整数据目录；凭据不包含在普通目录备份内。开发测试可通过 `KB_DATA_DIR` 指定隔离目录，测试脚本不会操作正式数据。

测试版单文件上限 50MB，PDF 200 页，一次最多 20 个附件，单次模型证据约 28000 字。超限全文总结会拒绝发送并要求拆分，尚无分层全文总结。知识列表最多显示 200 条，关键词搜索扫描最近 5000 条。MD 保留原始文本，DOCX 使用正文块位置；图片、页眉页脚及复杂表格版式可能遗漏。PDF 无文字页面会明确提示，不做 OCR。

**尚未完成：**OCR、旧 DOC、语义向量索引、概念级同义去重、复杂文档质量验收、推荐质量实测、完整故障注入、运行时资源测量和干净机器安装包验收。模型校验确认结构与引用 ID 有效，不能证明每个结论都被引用支持；实际内容仍需核对。当前阅读器安全显示文本，不执行或直接渲染来源中的 HTML。

## 验证与版本管理

```powershell
npm run check
npm run test:ui
```

`check` 包含命名、文件头、函数规模、分层边界、Prettier／Ruff、严格类型、Python 与宿主边界测试及构建。格式由 `.prettierrc.json` 和 `ruff.toml` 定义；新增开发工具 Prettier 锁定为 3.6.2，既有依赖未升级。协议说明及两端共用样例位于 [contracts](contracts/protocol.md)。自动检查不代替行为和注释评审。

桌面测试使用独立 Electron profile、临时数据目录和本地合成文件，可与正式运行实例共存；本版报告与截图保存在忽略提交的 `artifacts/test0.03/`。执行桌面测试前须先构建。

Git 默认分支为 `main`，本版标签为 `test0.03`；npm 使用预发布版本 `0.0.1-test.0.3`。远程仓库为 [GitHub KnowledgeBase](https://github.com/20050404yxc-collab/KnowledgeBase)，版本历史保留开发前基线和各次迭代；依赖环境、模型、编译产物、用户数据和秘密文件不提交。
