# 本地语义能力：第三方许可来源

本目录保存上游许可原文，供冻结后台构建时收集；模型权重不提交到仓库，也不随源码自动下载。`scripts/build_worker.py` 对 wheel 缺少许可文件的指定版本使用本目录原文，版本变化须重新核对。

| 材料 | 上游来源 | 用途 |
|---|---|---|
| `bge-small-zh-v1.5-LICENSE.txt` | [FlagEmbedding MIT LICENSE](https://github.com/FlagOpen/FlagEmbedding/blob/master/LICENSE)；[原始 BGE 模型卡](https://huggingface.co/BAAI/bge-small-zh-v1.5)标记 MIT | 保留模型原作者声明；[Xenova 转换仓库](https://huggingface.co/Xenova/bge-small-zh-v1.5)同样标记 MIT |
| `tokenizers-0.23.3-LICENSE.txt` | [tokenizers v0.23.3 LICENSE](https://github.com/huggingface/tokenizers/blob/v0.23.3/LICENSE) | Apache 2.0；补充当前 Windows wheel 未携带的许可原文 |
| `flatbuffers-25.12.19-LICENSE.txt` | [flatbuffers v25.12.19 LICENSE](https://github.com/google/flatbuffers/blob/v25.12.19/LICENSE) | Apache 2.0；补充 ONNX Runtime 间接依赖的许可原文 |

2026-10-24 核对。其余 Python 运行依赖从已安装 distribution 收集原始 LICENSE／NOTICE，生成 `build/notices/python/manifest.json`；缺失材料时构建失败。本记录不替代随分发产物携带完整许可证的要求。

语义模型固定转换提交 `75c43b069aac4d136ba6bc1122f995fedcfd2781`。资源大小、SHA-256、实现方式与本机实测见[语义模型验收](../确认页/个人知识库/语义模型验收.md)。
